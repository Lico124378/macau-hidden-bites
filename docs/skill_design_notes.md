# 巷味濠江 Macau Hidden Bites - 澳门街巷餐饮智能推荐 Agent

## 技能概述

本技能用于在 QwenPaw 中搭建一个面向澳门街巷餐饮小店的 AI 智能推荐 Agent。核心价值：
- **不是榜单推荐**：不依赖网红热度，而是基于用户实时需求精准匹配
- **三家精准推荐**：直接给出最适合的 3 家店，说明为什么推荐、推荐点什么、预估多少钱
- **本地知识库**：将街头巷尾的居民餐饮店转化为可被 AI 理解的结构化数据

**适用场景**：澳门智慧旅游、旧区活化、社区商户曝光、本地餐饮文化推广

---

## 前置条件

1. **QwenPaw 环境**：已安装并运行 QwenPaw v0.2+
2. **工作区**：已创建 agent 工作区（如 `~/.qwenpaw/workspaces/macau_hidden_bites/`）
3. **数据源**：已准备或开始采集澳门街巷餐饮店铺的结构化数据
4. **地图 API**（可选）：用于距离计算与路线规划（百度地图/高德地图/OpenStreetMap）

## 核心工作流

```
用户输入需求 → 需求解析 → 用户画像分析 → 候选店铺筛选 → 四系数排序 → 生成三家推荐 → 输出到店提示卡
```

### 步骤 1：用户需求解析

Agent 需识别以下意图要素：
| 要素 | 示例 | 说明 |
|------|------|------|
| 餐品类型 | 咖喱汤面、云吞面、甜品 | 可多值 |
| 距离偏好 | 离我近一点、在 XX 附近 | 需结合用户定位 |
| 价格预期 | 不要太贵、预算 50 以内 | 对应价格档位 |
| 支付方式 | 最好用微信支付、可 MPay | 便利系数筛选 |
| 场景需求 | 适合早餐、适合宵夜、适合拍照 | 场景标签匹配 |
| 特殊要求 | 有座位、可打包、有空调 | 附加便利信息 |

### 步骤 2：用户画像分析

基于需求生成临时画像，用于排序权重调整：
- **游客型**：权重偏向 便利系数 > 距离 > 好评 > 价格
- **街坊型**：权重偏向 价格 > 好评 > 距离 > 便利
- **探索型**：权重偏向 好评 > 特色标签 > 距离 > 价格
- **效率型**：权重偏向 距离 > 便利 > 价格 > 好评

### 步骤 3：候选店铺筛选

使用标签体系进行初筛：
1. 匹配餐品类型标签
2. 过滤距离范围（如 3km 内）
3. 过滤价格档位（如 低/中）
4. 匹配支付方式（如 可微信支付）
5. 匹配场景标签（如 适合早餐）

### 步骤 4：四系数排序

| 系数 | 权重范围 | 计算方式 | 说明 |
|------|----------|----------|------|
| **距离系数** | 0-25 | `25 * (1 - 实际距离/最大距离)` | 越近分越高 |
| **好评系数** | 0-25 | `(平均评分/5) * 25` | 基于真实评价 |
| **价格系数** | 0-25 | 越接近用户预期分越高 | 非绝对低价，而是匹配度 |
| **便利系数** | 0-25 | 每匹配一个便利标签 +5，满分 25 | 支付方式、交通、服务等 |

**总分** = 距离系数 + 好评系数 + 价格系数 + 便利系数（满分 100）

### 步骤 5：生成三家推荐

取 Top 3 店铺，按以下格式输出：

```
📍 推荐 1：[店名]
   距离：XX m / XX min 步行
   推荐菜品：[具体菜品]（价格：MOP XX）
   推荐理由：[结合四系数说明]
   支付方式：[列出可用方式]
   交通提示：[公交/步行指引]
   注意事项：[如下车需按铃、只收现金等]

📍 推荐 2：...
📍 推荐 3：...
```

## 标签治理机制

### 自查规则

Agent 在推荐前应执行以下自查：

1. **标签冲突检测**
   - `cash_only` 与 `wechat_pay` 不应同时存在
   - `适合早餐` 与 `适合宵夜` 可同时存在（全天候），但需核实营业时间

2. **标签完整性检查**
   - 每家店铺必须有：`food_tags`、`price_level`、`payment_methods`
   - 缺失关键字段的店铺不参与推荐，标记为 `待完善`

3. **标签合理性检查**
   - `人均消费` 与 `price_level` 是否匹配
     - low: 0-50 MOP
     - medium: 50-100 MOP
     - high: 100+ MOP

4. **距离合理性检查**
   - 推荐店铺距离用户不应超过 `max_distance_km`（默认 3km）
   - 若用户无明确距离要求，按 3km 筛选

### 标签更新流程

```
AI 初标 → 人工复核 → 标签入库 → 定期维护
```

1. **AI 初标**：基于店铺图片、菜单、基础信息自动生成标签
2. **人工复核**：调研人员或店主确认/修改标签
3. **标签入库**：更新至 shops.csv 与 tags 目录
4. **定期维护**：每季度检查标签有效性，处理闭店、搬迁、菜单变更

## 使用示例

### 用户输入
> "我想吃咖喱汤面，离我近一点，不要太贵，最好可以用微信支付。"

### Agent 处理流程
1. 解析需求：餐品=咖喱汤面，距离偏好=近，价格=低/中，支付=微信支付
2. 用户画像：游客型（推断）
3. 候选筛选：匹配 `curry` 标签 + `near_bus` + `low/medium` 价格 + `wechat_pay`
4. 四系数排序：计算每家店铺的总分
5. 输出三家推荐

### Agent 输出示例
```
📍 推荐 1：祥记面家
   距离：约 350m / 步行 5 min
   推荐菜品：咖喱汤面（MOP 32）、咖喱鱼蛋（MOP 15）
   推荐理由：距离最近，咖喱汤面评分 4.3，支持微信支付
   支付方式：微信支付、MPay、现金
   交通提示：步行即可到达，从新马路方向沿营地大街直行
   注意事项：店面不大，高峰时段需等位；营业时间 07:00-21:00

📍 推荐 2：六记粥面
   距离：约 600m / 步行 8 min
   推荐菜品：云吞面（MOP 38）、咖喱汤面（MOP 35）
   推荐理由：价格适中，街坊好评率高，有空调
   支付方式：微信支付、支付宝、现金
   交通提示：靠近巴士站，下车后步行 2 分钟
   注意事项：有座位，适合慢慢吃；营业时间 08:00-22:00

📍 推荐 3：冠环球面食
   距离：约 1.2km / 步行 15 min
   推荐菜品：猪扒面（MOP 42）、咖喱汤面（MOP 36）
   推荐理由：特色猪扒面口碑好，支持多种支付方式
   支付方式：微信支付、MPay、支付宝、现金
   交通提示：可乘公交至 XX 站下车，步行 3 分钟
   注意事项：猪扒面每日限量，建议早去；营业时间 10:00-20:00
```

## 扩展能力

### 多语言支持
- 支持中文（简体/繁体）、英文、葡文界面
- 标签体系保留中文，输出时按用户语言自动翻译

### 实时定位集成
- 接入用户 GPS 定位，自动计算距离
- 支持离线地图缓存（澳门本地）

### 社交分享
- 生成推荐卡片（图片格式），支持分享到社交平台
- 包含店名、地址、推荐菜品、二维码（导航链接）

### 店主入驻
- 提供小程序/H5 表单，店主自助提交店铺信息
- 上传菜单照片，AI 自动识别菜品生成标签
- 审核通过后入库

## 注意事项

1. **数据真实性**：推荐基于真实店铺数据，不编造、不虚构
2. **标签准确性**：AI 初标需人工复核，避免错误标签误导用户
3. **距离计算**：使用步行距离而非直线距离，更贴近实际体验
4. **营业时间**：推荐时需检查店铺当前是否营业，非营业时间不推荐或明确提示
5. **隐私保护**：不收集用户敏感信息，仅记录必要的需求用于推荐
6. **合规性**：遵守澳门数据保护法规，店铺信息需获得授权或为公开信息
